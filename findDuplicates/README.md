# 檔案重複命名整理工具 (Duplicate File Renamer)

這是一個使用 Node.js 編寫的命令列工具，旨在掃描指定資料夾，找出因下載、複製或備份而產生的命名相似的檔案（例如 `photo.jpg`, `photo (1).jpg`, `photo_2.jpg`），並將它們標準化為一致的命名格式。

## 功能特色

- **智慧掃描**：根據檔案的「基準名稱」找出可能的重複檔案群組。
- **互動式介面**：透過簡單的問答引導使用者完成操作。
- **安全重新命名**：
  - 在執行任何修改前，會將原始檔案**備份**到您指定的資料夾。
  - 採用安全的暫存檔名機制，避免在過程中因檔名衝突而覆蓋檔案。
- **標準化命名**：將重複檔案群組重新命名為 `檔案名稱.ext`, `檔案名稱_1.ext`, `檔案名稱_2.ext`... 的格式，方便整理。
- **自訂排除規則**：允許使用者輸入檔名開頭，以排除特定模式的檔案（例如 `LINE_ALBUM`）。

## 環境需求

- Node.js (建議版本 16.x 或以上)

## 如何使用

1.  將 `findDuplicates.js` 檔案儲存到您的電腦中。
2.  打開您的終端機 (Terminal) 或命令提示字元 (Command Prompt)。
3.  使用 `cd` 指令切換到 `findDuplicates.js` 檔案所在的目錄。
4.  執行以下指令啟動程式：
    ```bash
    node findDuplicates.js
    ```
5.  依照畫面上出現的提示，依序輸入所需資訊：
    - **要掃描的資料夾路徑**：預設為當前目錄 (`./`)。
    - **是否啟用重新命名功能**：輸入 `y` 才會執行檔案修改。
    - **備份資料夾路徑**：若啟用重新命名，此為必填項目。
    - **要排除的檔名開頭**：可輸入用逗號分隔的列表，或直接按 Enter 跳過。

程式會先掃描並列出所有找到的重複檔案群組。如果您選擇了啟用重新命名，它才會繼續執行備份和重新命名的流程。
